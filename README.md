# WishLoom

WishLoom is a handmade gifting website created for my pastime startup idea.

It is a full-stack MERN project where users can explore and purchase handmade products like embroidery gifts, crochet items, hampers, scrapbooks, and personalized keepsakes.

The project was built to practice full-stack development while also creating something creative and meaningful.

---

## Features

- User authentication and authorization
- Admin dashboard
- Product management
- Order management
- Shopping cart functionality
- Product filtering and collections
- Responsive UI
- Contact form using EmailJS
- Frontend and backend deployment on Vercel

---

## Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

### Clone the repository

```bash
git clone https://github.com/your-username/MyStartup.git
```

### Install frontend dependencies

```bash
cd frontend
npm install
```

### Install backend dependencies

```bash
cd backend
npm install
```

---

## Environment Variables

Create a `.env` file inside backend folder and add:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=9000
```

---

## Run the Project

### Start backend

```bash
cd backend
npm run dev
```

### Start frontend

```bash
cd frontend
npm run dev
```
